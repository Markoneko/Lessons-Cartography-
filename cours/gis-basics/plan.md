[PPT 20] | QCM : combien de valeurs différentes peut prendre un pixel codé sur 8 bits ? |  |

| 3.4 | Le vecteur : point, ligne, surface | Socle | à réaliser | Les primitives géométriques : le point (une borne), la ligne (un axe de route), la surface (une commune). [PPT 22] | classer six objets (arbre isolé, rivière, parcelle, ligne électrique, commune, puits) ; puis question : une rivière est-elle toujours une ligne ? |  |
